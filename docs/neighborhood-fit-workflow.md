# Neighborhood Fit Workflow

This note is the operating rule set for the neighborhood-fit quiz, photo drafts, and review packets.

## Source of truth

- `docs/neighborhood-fit-content-locks.md` is the only place that counts as approved and locked.
- `Copy Status: Approved` means the written copy is locked.
- `Status: Approved` means the photo is locked.
- Anything else is scratch space until it is shown in chat and explicitly approved.
- Keep all stable image assets in the repo. Do not hotlink random URLs in final quiz or email assets.

## Working order

Move top-to-bottom through the current quiz order and do not jump ahead.

- Raleigh
- Cary
- Wake Forest
- Morrisville
- Durham
- Apex
- Holly Springs

## Photo rules

- Use real photos only.
- Prefer drone or neighborhood street shots.
- Do not use AI-generated images, placeholders, or decorative image treatments.
- If a neighborhood has a better real photo option, show it in chat before locking it in.
- If a neighborhood is not a real neighborhood, replace it with a real neighborhood before moving on.

## Copy rules

- Keep the final email copy simple and readable.
- Use this structure:
  - neighborhood photo
  - neighborhood name
  - broad price range
  - home-age / style summary
  - short plain description
- Avoid fancy formatting, overlays, or extra visual clutter.
- Show draft copy in chat first, then lock it only after approval.

## Review packet rules

- Build one photo-review packet for the remaining unlocked neighborhoods when possible.
- Include only neighborhoods that are not locked yet.
- Show 3 unique real photo options per neighborhood.
- Include the copy draft below each neighborhood so image choice and wording stay together.
- Prefer drone or neighborhood street shots when selecting options.
- Include all remaining neighborhoods in city order so review stays linear.
- Open the PDF for visual review before asking for final approval.
